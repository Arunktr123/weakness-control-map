# Privacy

Weakness → Control Map does not collect, store or transmit any data.

- The plugin is one skill made of Markdown and JSON text files. It contains no scripts, hooks, MCP servers, commands,
  telemetry or background processes, and it does not change any settings or permissions.
- When the skill is used, your agent searches the bundled data files for the CWE, CAPEC, control or SSDF ids (or the
  words) taken from your request, using the agent's own search tool. The plugin itself makes no network connections,
  writes no files and keeps no logs or history.

What you type and what the agent does with the results stay within your agent application and are governed by that
application's own privacy terms.

Questions: open an issue at https://github.com/Arunktr123/weakness-control-map/issues
