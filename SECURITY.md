# Security policy

This plugin contains only Markdown, JSON and text files: no code runs when it is installed or used, it makes no network
connections and it collects no data.

## Reporting a problem

- **Security issue** (for example a malicious or misleading change to a data file or to the skill's instructions):
  use GitHub's private vulnerability reporting for this repository (Security tab, "Report a vulnerability"). Please do
  not open a public issue for it. Reports are acknowledged within 7 days and investigated with reasonable care.
- **Incorrect mapping or a data error:** open a normal issue at https://github.com/Arunktr123/weakness-control-map/issues
  with the CWE or CAPEC id, the control or SSDF task, and what should change.

## Scope

Only the latest released version is maintained. Fixes are released as a new version and recorded in
[CHANGELOG.md](CHANGELOG.md).
